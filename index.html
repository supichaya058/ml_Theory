1. K-Means คืออะไร?

K-Means เป็นอัลกอริทึมสำหรับ Unsupervised Learning ที่ใช้จัดกลุ่มข้อมูลที่ไม่มี Label ออกเป็น K กลุ่ม (Clusters) โดยพิจารณาจากระยะห่างระหว่างข้อมูลกับจุดศูนย์กลาง หรือ Centroid

กระบวนการจะทำซ้ำจนกว่าสมาชิกของแต่ละกลุ่ม และตำแหน่งของ Centroid จะไม่เปลี่ยนแปลง

5. การคำนวณ Centroid ใหม่

เมื่อแบ่งข้อมูลเข้าสู่ Cluster แล้ว จะคำนวณค่าเฉลี่ยของข้อมูลในแต่ละ Cluster

C₁,new = (2 + 4) / 2 = 3.0
C₂,new = (10 + 12 + 14) / 3 = 12.0

6. Final Result & Convergence

เมื่อนำ Centroid ใหม่ C₁ = 3.0 และ C₂ = 12.0 ไปจัดกลุ่มข้อมูลอีกครั้ง พบว่าสมาชิกของแต่ละ Cluster ไม่เปลี่ยนแปลง

Cluster 1 = {2, 4} → Centroid = 3.0
